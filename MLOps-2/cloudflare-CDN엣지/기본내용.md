# Cloudflare 실험 진행 상황 정리

## 현재 상태

* Cloudflare 계정 생성 완료
* Cloudflare 대시보드 접속 확인
* Workers & Pages 프로젝트 존재

  * noisy-lake-5d45
* 아직 별도 도메인은 구매하지 않음
* 목적:

  * Cloudflare CDN 및 프록시 기능 확인
  * 비용을 최소화하면서 Cloudflare 서비스 테스트
  * 가능하면 도메인 구매 전에 무료로 실험

---

## 확인한 내용

### 1. 도메인 구매 후 CDN 확인 가능

도메인을 Cloudflare에 연결하면:

* DNS 관리
* 무료 SSL
* CDN
* DDoS 보호
* 캐싱

사용 가능

CDN 적용 여부는:

* 브라우저 개발자도구(Network)
* curl 명령어

로 확인 가능

확인 헤더 예시:

```text
server: cloudflare
cf-ray: xxxxx
cf-cache-status: HIT
```

---

### 2. Workers 연결 가능

현재 존재하는:

* noisy-lake-5d45

프로젝트는 Workers/Pages 프로젝트

향후:

* mydomain.com
* api.mydomain.com

같은 사용자 도메인을 연결 가능

---

### 3. 도메인 없이도 실험 가능

Cloudflare Tunnel 사용

장점:

* 무료
* HTTPS 자동 적용
* 공유기 포트포워딩 불필요
* 공인 IP 불필요
* 로컬 서버 외부 공개 가능

---

## 현재 추천 실험

### 로컬 웹서버 실행

Python 예시:

```bash
python -m http.server 8000
```

---

### Cloudflare Tunnel 실행

설치 후:

```bash
cloudflared tunnel --url http://localhost:8000
```

실행

---

### 결과

Cloudflare가 임시 주소 발급

예:

```text
https://random-name.trycloudflare.com
```

---

### 테스트

다른 기기(휴대폰 LTE 등)에서 접속

확인 사항:

* 외부 접속 가능 여부
* HTTPS 동작 여부
* Cloudflare 경유 여부
