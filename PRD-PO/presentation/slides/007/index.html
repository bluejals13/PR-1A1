IMPLEMENTED VERIFIED
1. M:N 정규화 RBAC 데이터 모델 DATA MODEL

사용자(User)와 권한(Permission) 사이에 역할(Role)을 매핑 테이블(`user_roles`, `role_permissions`)로 정규화하여 권한 변경 시 유연한 확장을 지원합니다.

User users id, email, name
M:N (`user_roles`) ➔
Role roles ROLE_ADMIN, ROLE_USER
M:N (`role_permissions`) ➔
Permission permissions USER_READ, AUTH_MANAGE
Menu Access Control: `roles` ➔ `role_menus` ➔ `menus` (사이드바 인가 메뉴 동적 렌더링)
2. Spring Security 인가 판정 파이프라인 FILTER CHAIN
01
요청 수신 및 토큰 추출

`JwtAuthenticationFilter`가 `Authorization: Bearer` 헤더 파싱

02
권한 로딩 & SecurityContext 주입

`UserAuthorityService`를 통해 Role & Permission을 `GrantedAuthority` 목록으로 주입

03
엔드포인트 접근 권한 검사

`@PreAuthorize("hasAuthority('ADMIN')")` 또는 `requestMatchers` 인가 판정

권한 일치 200 OK / 정상 응답
권한 부재 403 Forbidden 차단
