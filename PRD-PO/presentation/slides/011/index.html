TS-01-REDIS VERIFIED

Redis 타임아웃 및 스레드 블로킹

Symptom:

Redis 다운 시 60초 커맨드 대기로 프론트엔드 흰 화면(Blank Screen) 노출

Root Cause:

Lettuce 커맨드 타임아웃 기본값(60s) 미설정으로 인한 스레드 대기 전파

Resolution:

타임아웃 2000ms(2초) 단축 및 503 Service Unavailable 에러 격리

TS-001 VERIFIED

JWT Refresh 401 무한 루프

Symptom:

만료 토큰 요청 시 인터셉터와 서버 간 401 무한 재시도 루프 발생

Root Cause:

클라이언트 인터셉터 내 재시도 탈출 조건(Exit Condition) 결여

Resolution:

Single-Flight 패턴 구축 및 401 수신 시 즉시 세션 초기화 ➔ 로그인 리다이렉트

TS-003 VERIFIED

Docker Redis localhost 바인딩 실패

Symptom:

Docker 환경에서 Spring Boot가 `localhost:6379` 접속 실패(Connection Refused)

Root Cause:

컨테이너 격리 네트워크 특성 (`localhost`는 컨테이너 자기 자신 참조)

Resolution:

${SPRING_REDIS_HOST:localhost} 환경변수 분리 및 Docker Compose redis 주입
