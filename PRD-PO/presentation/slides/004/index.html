1. Java 17 Record 불변 DTO IMMUTABILITY

요청/응답 객체에 `record`를 사용하여 Setter 부수 효과를 차단하고, 영속성 엔티티의 변경 감지(Dirty Checking) 오작동 및 데이터 오염을 방지합니다.

public record LoginRequest(@NotBlank String email, @NotBlank String password) {}
2. 통일된 API 응답 (`ApiResponse`) STANDARDIZED

모든 API 응답을 `success`, `data`, `message`, `errorCode` 포맷으로 통일하여 클라이언트 통신의 예측 가능성과 일관성을 확보합니다.

public record ApiResponse<T>(boolean success, T data, String message, String errorCode) {}
3. 중앙 집중식 예외 핸들링 EXCEPTION ADVICE

`@RestControllerAdvice` 기반 `GlobalExceptionHandler`를 통해 비즈니스 예외와 보안 예외를 표준 에러 응답 포맷으로 가공합니다.
