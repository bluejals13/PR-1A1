무상태(Stateless) 인증의 3대 보안 딜레마 & 해결 아키텍처

ARCHITECTURAL DECISION
1. Token Revocation Gap 무효화 불가
로그아웃 후에도 토큰 유효

순수 Stateless JWT는 사용자가 로그아웃해도 만료 시각(1시간)까지 서명이 유효하여 토큰 탈취 시 API 호출을 즉시 차단할 방법이 없음.

2. Replay Attack Risk 탈취 토큰 재사용
장기 Refresh Token 공격 노출

7일간 유효한 Refresh Token이 고정되어 있으면 탈취 시 공격자가 무한히 새 Access Token을 발급받아 지속적인 비인가 접근 가능.

3. Container Isolation 도커 루프백 실패
`localhost` 바인딩 거부

Docker 격리 환경에서 컨테이너 간 통신 시 `localhost`는 자기 자신을 가리켜 Redis/DB 커넥션 거부(Connection Refused) 발생.
